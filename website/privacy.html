Privacy

We don't collect anything.

Last updated: November 6, 2026

The app

  • Magic Paint doesn't collect, store or send any personal information.
  • There are no accounts, ads, analytics, trackers or in-app purchases.
  • The desktop app doesn't connect to the internet. Brushes, pages, sounds and Drip's voice are all built in.
  • The painting in progress, the chosen language and the sound setting are saved only on your computer, inside the app's own storage.
  • Paintings you save are written only to the place you pick in the Save window.

The website

  • This website has no cookies, no analytics and no tracking scripts.
  • It's hosted on GitHub Pages, and downloads are served by GitHub Releases. Like any web host, GitHub may keep standard technical logs (such as IP addresses) to run and secure its service. See GitHub's privacy statement.
  • The download section asks GitHub's public API for the latest version number. No information about you is sent along with that request.
  • The browser version (Play online) saves the current painting in your browser's local storage on your device only.

Children

Magic Paint is made for children, which is why it collects no data from anyone. Because no personal information is collected, none can ever be shared or sold.

Changes

If this ever changes, we'll update this page before the app changes, and the date at the top will show it.
